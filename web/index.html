Permission Set Converter

Turn Business Central permission set exports (XML or CSV) into AL permission set files. Everything runs in your browser. Nothing is uploaded.

1Add your permission set files

An XML file from Export Permission Sets, or a CSV exported to Excel from a permission set's Permissions page. A CSV becomes one permission set named after the file.

Drag & drop XML or CSV files here, or click to browse

    2Use object names instead of IDs (recommended)

    Drop the .app files from your project's .alpackages folder (Base Application, System, your extensions). For apps without symbols you can also drop a .csv (50100,My Table) or .json ({"50100": "My Table"}) table list.

    Drag & drop .app / .csv / .json files here, or click to browse
